Sobre Mim - Victor

Bem-vindo ao meu portfólio. Aqui registro parte da minha trajetória de estudos, projetos e evolução na área de tecnologia.

Meu primeiro contato com programação — 8º ano

EduTech

Meu primeiro contato com programação aconteceu durante o 8º ano, quando comecei a conhecer o universo da tecnologia por meio do programa EduTech.

Foi uma experiência principalmente introdutória e exploratória. Eu ainda estava descobrindo como os programas funcionavam e como era possível transformar ideias em algo utilizando tecnologia.

Essa experiência despertou minha curiosidade e acabou sendo uma das primeiras etapas da minha trajetória na área de desenvolvimento de software.

Alura

Durante o Ensino Fundamental, participei do programa EduTech utilizando a plataforma Alura, entre 2022 e 2023.

Nesse período, tive contato introdutório com diversas áreas da tecnologia, incluindo Java, JavaScript, HTML, CSS, SQL, Django, React, Ciência de Dados, Machine Learning e desenvolvimento de jogos.

Também conheci conceitos e ferramentas como GitHub, Programação Orientada a Objetos, bancos de dados, APIs e desenvolvimento web.

Embora eu tenha visto grande parte desses conteúdos apenas de forma introdutória, essa experiência foi importante para conhecer diferentes caminhos dentro da programação.

HTML5 e CSS3

Também tive meus primeiros contatos com HTML5 e CSS3.

Comecei a entender como uma página da internet é estruturada e como diferentes elementos podem ser utilizados para organizar textos, imagens e outros conteúdos.

Foi nesse momento que comecei a perceber que uma página da internet possui uma estrutura que pode ser planejada e construída.

Scratch

Outro dos meus primeiros contatos com programação aconteceu através do Scratch.

Por ser uma ferramenta visual, ele me ajudou a compreender conceitos básicos de lógica de programação, como condições, repetições, eventos e organização de instruções.

O Scratch me ajudou a entender que programar é transformar uma ideia em uma sequência de instruções.

9º ano — Pensamento Computacional

No 9º ano, continuei minha formação com conteúdos relacionados ao Pensamento Computacional.

Essa etapa foi importante para começar a desenvolver uma maneira mais estruturada de pensar na resolução de problemas.

Passei a compreender melhor como dividir problemas em partes menores, identificar padrões, organizar informações e criar uma sequência de passos para chegar a uma solução.

Esses conceitos se tornaram uma base importante para meus estudos posteriores de programação.

1º ano do Ensino Médio — Robótica

No 1º ano do Ensino Médio, tive contato com robótica.

Essa experiência mostrou que a programação poderia ser utilizada não apenas em computadores, mas também para controlar dispositivos e criar soluções relacionadas ao mundo físico.

A robótica também contribuiu para meu desenvolvimento em lógica, projetos e resolução de problemas.

Foi uma experiência importante para perceber que o código pode interagir diretamente com o mundo físico.

2º ano do Ensino Médio — SESI SENAI e Desenvolvimento de Sistemas

No 2º ano do Ensino Médio, entrei no SESI SENAI e comecei o curso integrado de Desenvolvimento de Sistemas.

Foi nessa etapa que comecei a estudar programação de maneira mais estruturada e passei a compreender melhor diferentes etapas do desenvolvimento de software.

Comecei a entender que desenvolver um sistema não significa apenas escrever código.

É necessário compreender o problema, planejar uma solução, organizar o projeto e pensar em como suas diferentes partes irão funcionar em conjunto.

Lógica de programação com Portugol

Um dos primeiros conteúdos estudados foi lógica de programação utilizando Portugol.

Antes de aprofundar meus conhecimentos em linguagens específicas, comecei a desenvolver minha capacidade de pensar em algoritmos e estruturar soluções.

Estudei conceitos como variáveis, operadores, estruturas condicionais, estruturas de repetição e entrada e saída de dados.

Aprender lógica antes de uma linguagem específica me ajudou a perceber que a linguagem é uma ferramenta, enquanto o raciocínio lógico está por trás da solução.

Primeiro contato com Python

Depois de estudar lógica de programação, tive meu primeiro contato com Python.

A linguagem acabou se tornando uma das principais ferramentas da minha trajetória de estudos.

Comecei pelos fundamentos e avancei gradualmente para estruturas condicionais, estruturas de repetição, listas, tuplas, dicionários, funções e módulos.

Foi com Python que comecei a perceber de forma mais concreta o potencial de transformar ideias em programas funcionais.

3º ano do Ensino Médio

No 3º ano do Ensino Médio, comecei a buscar uma evolução maior nos meus conhecimentos.

Passei a estudar com mais autonomia e comecei a procurar maneiras de colocar em prática aquilo que estava aprendendo.

Essa fase também foi marcada pela criação de projetos próprios e pela exploração de diferentes tecnologias.

Evolução com Python

Continuei evoluindo com Python e comecei a desenvolver projetos mais completos.

Um dos projetos que mais contribuiu para meu aprendizado foi o Fliperama do Victor.

O projeto começou com jogos simples e evoluiu para envolver sistemas de jogador, carteira, apostas, partidas, vitórias, derrotas, empates, ranking e organização do código em diferentes módulos.

Durante o desenvolvimento, comecei a perceber que fazer um código funcionar é apenas uma parte do processo.

Também é necessário organizar o projeto, dividir responsabilidades, identificar erros e procurar maneiras melhores de estruturar uma solução.

Esse projeto representa uma parte importante da minha evolução.

Relembrando C++ com IoT

Durante minha formação, também voltei a trabalhar com C++, principalmente em projetos relacionados à Internet das Coisas (IoT).

Essa experiência permitiu relembrar conceitos da linguagem e entender melhor a relação entre programação, dispositivos eletrônicos e sistemas físicos.

Foi interessante perceber como o código pode ultrapassar a tela do computador e controlar elementos do mundo real.

Primeiro contato com Java

Também tive meu primeiro contato com Java.

Conhecer outra linguagem foi importante para perceber que existem diferentes maneiras de resolver problemas utilizando programação.

Também pude comparar conceitos que já conhecia em Python com uma linguagem que possui características e uma estrutura diferentes.

Conhecer diferentes linguagens começou a mostrar que aprender programação vai além de dominar uma única tecnologia.

Modelagem de sistemas

Outro conhecimento importante foi meu primeiro contato com modelagem de sistemas.

Comecei a entender que, antes de desenvolver um sistema, é importante compreender o problema, identificar seus componentes e planejar como eles irão se relacionar.

Essa etapa ampliou minha visão sobre desenvolvimento de software.

Metodologias de trabalho

Durante minha formação, também tive contato com metodologias de desenvolvimento e formas de trabalho utilizadas em projetos de software.

Comecei a compreender melhor conceitos relacionados à organização de projetos, divisão de tarefas, planejamento, trabalho em equipe e acompanhamento do desenvolvimento.

Isso me ajudou a perceber que o desenvolvimento profissional envolve tanto conhecimento técnico quanto organização e colaboração.
