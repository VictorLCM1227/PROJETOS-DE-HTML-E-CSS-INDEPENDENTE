Conhecimentos

JavaScript

Estou estudando JavaScript para ampliar meus conhecimentos em desenvolvimento Web e aprender a adicionar interatividade às páginas.

PHP

Estou estudando PHP como parte da minha formação em desenvolvimento Web e para compreender melhor o desenvolvimento no lado do servidor.

Java

Tive contato com Java durante minha formação em Desenvolvimento de Sistemas, conhecendo os fundamentos da linguagem e sua utilização na programação.

C++

Também tive contato com C++ durante minha formação, principalmente em atividades relacionadas à programação e desenvolvimento de sistemas.
