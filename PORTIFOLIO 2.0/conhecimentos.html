Conhecimentos

Nesta página apresento alguns dos conhecimentos que venho adquirindo e que podem ser úteis na área de tecnologia.

Linguagens de Programação

Python

Com Python, aprendi diversos conceitos fundamentais da linguagem. Estudei variáveis, tipos de dados, estruturas condicionais, estruturas de repetição, tuplas, listas, dicionários, funções, tratamento de erros e modularização. Com esses conhecimentos, desenvolvi diversos projetos independentes que publiquei no meu GitHub.

Java

Com Java, adquiri conhecimentos básicos durante as aulas no colégio. Programei alguns scripts que criam janelas e também cheguei a desenvolver uma tela de login.

C++

Com C++, também tive contato com conhecimentos básicos. Estudei a linguagem durante a matéria de IoT no SESI SENAI e no curso de robótica. Acho interessante sua utilização em projetos envolvendo Arduino.

Desenvolvimento Web

HTML5

Com HTML5, comecei a aprender mais sobre desenvolvimento de sites. Meu conhecimento ainda está em desenvolvimento, mas gosto de criar páginas e quero continuar praticando. Você pode conhecer alguns dos meus projetos diretamente pelo meu GitHub ou aqui mesmo no meu site, na página sobre os meus projetos.

CSS3

Com CSS3, estou aprendendo a estilizar páginas Web e seus elementos. É uma habilidade que ainda está em desenvolvimento, mas considero uma área muito interessante.

Outras Tecnologias

JavaScript

Ainda estou estudando JavaScript e não desenvolvi muitos projetos com a linguagem. Meu objetivo é aprender como utilizá-la para adicionar interatividade às páginas Web.

PHP

Estou estudando PHP para conhecer melhor uma linguagem utilizada no desenvolvimento Web e aprender sobre desenvolvimento no lado do servidor.

SQL

Durante o curso técnico no SESI SENAI, tive contato com SQL e MySQL Workbench. Achei interessante trabalhar com bancos de dados e tenho interesse em aplicar esse conhecimento nos meus projetos.

Git e GitHub

Git e GitHub são algumas das tecnologias mais úteis que aprendi. Com eles, consigo armazenar, organizar e compartilhar meus projetos. Também posso clonar meus projetos no colégio, continuar o desenvolvimento e depois atualizar os arquivos sem precisar utilizar um pendrive.

VS Code

No VS Code tenho uma história que começou em 2022. É o meu editor favorito para escrever código, principalmente em Python e no desenvolvimento Web.

Pacote Office

Também possuo conhecimentos em ferramentas do pacote Office. Considero Excel e Word ferramentas úteis para organização de informações, documentos e dados.

Figma

Conheço o Figma e considero uma ferramenta interessante para planejar visualmente um site antes de começar seu desenvolvimento.

Tinkercad

Utilizei o Tinkercad para testar sistemas com Arduino, sensores e LEDs antes de utilizar os componentes físicos.

Conhecimentos Acadêmicos

Os conhecimentos acadêmicos também são importantes para a programação. Matemática, linguagens, ciências da natureza e ciências humanas podem contribuir para a forma como um projeto é planejado e desenvolvido.

Soft Skills

Por conta da minha trajetória acadêmica e profissional, desenvolvi experiências relacionadas à administração, organização e trabalho em equipe. Essas habilidades foram adquiridas nos ambientes que frequentei e nos cursos que fiz.
