Meus Projetos

Aqui apresento alguns dos projetos independentes que desenvolvi durante meus estudos de programação. Eles têm como principal objetivo colocar em prática os conhecimentos que venho adquirindo, experimentar diferentes áreas da tecnologia e desenvolver minha capacidade de resolver problemas por meio da programação.

Projetos em Destaque

Fliperama 2.0

O Fliperama 2.0 é um dos meus principais projetos em Python. Ele reúne diferentes jogos em uma única aplicação e possui uma estrutura organizada em módulos, incluindo sistemas de jogador, carteira, perfil, conquistas, ranking, loja, configurações e utilidades. O projeto foi criado para praticar lógica de programação, modularização, organização de código e desenvolvimento de uma aplicação maior.

ChatBot

O ChatBot é um projeto desenvolvido em Python dentro da área de Inteligência Artificial. O objetivo é explorar a criação de uma aplicação capaz de interagir com o usuário por meio de conversas e, ao mesmo tempo, estudar conceitos relacionados à inteligência artificial e à lógica de programação.

ToDo List

O ToDo List é uma aplicação criada para trabalhar com organização de tarefas. O projeto faz parte dos meus estudos de desenvolvimento de aplicações em Python e foi desenvolvido para praticar estruturas de dados, entrada de informações e organização de funcionalidades.

Calculadora Física

A Calculadora Física é um projeto desenvolvido para aplicar programação na resolução de cálculos relacionados à Física. A proposta é transformar fórmulas e operações matemáticas em uma ferramenta prática, utilizando Python e conceitos de computação científica.

Projetos Web

Portfólio 2.0

Meu portfólio é um projeto desenvolvido para apresentar minha trajetória na programação, meus conhecimentos, cursos e projetos independentes. Estou utilizando o desenvolvimento do próprio portfólio como uma forma de praticar HTML5 e CSS3 e, futuramente, outras tecnologias Web.

Todos esses projetos fazem parte da minha trajetória de aprendizado. Alguns são exercícios simples e outros estão em constante evolução, mas todos têm o mesmo objetivo: transformar o conhecimento estudado em prática e continuar desenvolvendo minhas habilidades como programador.
